# Tic Tac Toe

Play tic tac toe against the computer or a friend.

## Features

- Three computer difficulties, including an unbeatable one
- Two-player mode on the same device
- Winning line highlight
- Persistent scoreboard
- A How to play popup explains the rules

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
